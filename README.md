# 程序锁（AppLock）

免费的 macOS 程序锁：给指定应用加密码保护，无需订阅，不拦截网页，只锁程序本身。

打开被锁定的程序时，程序会被立即关闭并弹出密码框；输入正确密码后自动重新打开，取消则保持关闭。

## 功能

- 菜单栏常驻，不占用 Dock
- 添加任意已安装的 App 到「已锁定程序」列表
- 打开锁定程序时立即关闭，验证密码后自动重开
- 可选重新锁定时机：立即生效 / 2 分钟 / 5 分钟（指程序退出后多久恢复锁定）
- 开机自动启动
- 密码本地存储：随机盐 + 60,000 轮 SHA256，文件权限 0600
- 支持 Intel 与 Apple Silicon（通用二进制）

## 系统要求

macOS 15.0 及以上。

## 安装

从 [Releases](../../releases) 下载 `AppLock-x.x.dmg`，打开后把「程序锁」拖进 Applications。

首次打开时系统可能提示「无法验证开发者」，因为本项目没有 Apple 开发者签名：

- 打开「系统设置 → 隐私与安全性」，在页面底部点击「仍要打开」
- 或在终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/AppLock.app
```

## 使用

1. 点击菜单栏的锁图标，设置密码。
2. 点「添加程序」选择要保护的应用。
3. 打开「启用锁定」开关。

密码、已锁定列表与设置都保存在本机：

```
~/Library/Application Support/AppLock/
```

删除这个目录即可完全重置（包括忘记密码的情况）。

## 从源码构建

需要 Xcode 或 Command Line Tools。

```bash
./build.sh      # 生成 dist/AppLock.app
./package.sh    # 生成 dist/AppLock-<版本>.dmg
```

图标由 `AppIcon-1024.png` 自动生成 `.icns`，无需额外工具。

## 说明

这个工具定位是「防误用」，不是安全隔离。它以普通用户权限运行，通过监听应用启动来做拦截，无法阻止有管理员权限的人关闭它、替换它或直接修改应用包。请不要把它当成对抗恶意用户的防护手段。
